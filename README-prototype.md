# 错题任务中心

这是一个无依赖的中文教育 Web 原型，使用 HTML、CSS 和原生 JavaScript 实现。页面通过 `localStorage` 保存演示角色、题目选择、作答和提交结果，刷新后状态会保留。

## 启动

直接双击 `app.html` 即可预览；也可以在项目目录运行：

如果 4173 已经是本项目启动的服务，直接打开 IPv4 地址：

`http://127.0.0.1:4173/app.html`

如果 4173 属于其他项目，再在空闲端口启动本项目：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4174/app.html`。不要终止正在使用 4173 的服务。

## 演示入口

- 学生：李明，初一（3）班
- 家长：李明家长
- 老师：王老师

顶部左下角用户卡片中的角色选择器可切换视角。生产环境应由真实账号和服务端权限控制。

## 已实现

- 学生、家长、老师三套不同导航和首页信息层级
- 家长上传作业、识别确认、冲突提交复核、练习参数设置、练习生成
- 保存失败提示不阻断练习生成，并提供重新同步操作
- 学生逐题练习、选择题/填空题/解答题、自动保存、提交提醒、逐题答案与解析
- 老师待复核、冲突处理入口、班级诊断（排行、环图、趋势、矩阵）、练习布置
- 任务状态时间线、空状态/错误提示/加载反馈、辅助导出入口
- 响应式布局，移动端自动切换为单栏和垂直时间线

## 真实后端接入位置

当前 `app.js` 中的 `seed`、`loadState`、`saveState` 和 `submitPractice` 模拟了数据服务。接入后端时可将这几处替换为 `repository` 或 API service，页面层只保留状态更新和渲染逻辑。不要在前端写入飞书 Token 或其他敏感凭证。
